3. Этапы закупочной поставки (Supply)
   Этап 1 — Создание закупки (общий для RU и CN)

Действие: создать закупку (Supply)

Пользователь:

выбирает origin: Россия (RU) / Китай (CN)

выбирает поставщика

добавляет товары (SupplyItem), для каждой позиции:

товар

количество

цена за единицу вводится одним из способов:

RUB (цена за единицу в рублях)

CNY + курс (цена за единицу в юанях + курс юань→рубль)

система всегда хранит и использует цену в RUB:

если ввод RUB → unit_price_rub = input_rub

если ввод CNY → unit_price_rub = input_cny * rate

можно добавить примечание

Остатки: не меняются

Статус: Черновик
(закупка может сохраняться и редактироваться без передачи в ТК)

Этап 2 — Пред-ТК логистика (ветки RU и CN)
Ветка RU (Россия)

RU-1. Закупка сформирована (Черновик)

можно сохранять/редактировать

товар ещё не в пути “по системе”

RU-2. Передано в ТК
(это действие переводит закупку в общий путь)

выбрать ТК (перевозчик)

выбрать склад назначения (куда оприходуем, например Томск)

указать количество мест (обязательно)

можно указать трек-номер и/или стоимость ТК (опционально на этом шаге)

Статус → Доставляется на склад

Ветка CN (Китай)

CN-1. Закупка сформирована (Черновик)

можно сохранять/редактировать

CN-2. Оплачено поставщику (CNY)

фиксируется оплата (сумма/дата; курс может быть задан ранее или здесь)

автоматически переводит статус в:

Статус → В отправке по Китаю

CN-3. Принят карго

фиксируется факт приёмки карго (количество мест — обязательно)

автоматически переводит статус в:

Статус → Доставляется в Россию (карго)

CN-4. Прибыло карго в РФ / выставлен счёт / оплачено карго

фиксируется стоимость карго (RUB) и факт оплаты (если есть)

закупка может “лежать” в этом состоянии сколько угодно

CN-5. Передано в ТК
(точка слияния путей; дальше общий путь)

выбрать ТК (перевозчик)

выбрать склад назначения

количество мест подтягивается из карго (можно поправить при необходимости)

можно указать трек-номер и/или стоимость ТК (опционально на этом шаге)

Статус → Доставляется на склад

Этап 3 — Общий путь после передачи в ТК (RU и CN одинаково)

U-1. Доставляется на склад

указываем/уточняем трек-номер ТК (если не указали раньше)

указываем стоимость доставки ТК (RUB), когда появилась

U-2. Прибыло в город назначения (Томск)

U-3. Получено (ты забрал груз)

U-4. Оприходование

кнопка “Оприходовать на склад”

пользователь вводит только примечание (опционально)

Система:

берёт склад назначения из этапа “Передано в ТК”

берёт количество из закупки (SupplyItem)

распределяет логистику по единицам (карго + ТК)

создаёт партии (Batch)

увеличивает остатки на складе

Статус → На складе
